# LikeMinds Chat: React Native white-label example

A reference build showing the LikeMinds React Native Chat SDK wrapped in a custom app shell.

**Docs:** https://docs.likeminds.io/

## What this shows

- A **custom bottom-tab navigator** placing chat alongside app-specific tabs for announcements and
  profile, rather than chat owning the whole app
- **Bundled brand fonts** applied across the SDK's screens
- Building on `@likeminds.community/chat-rn-core` without forking it

Read this if you are integrating chat as one surface inside a larger product rather than as the
product itself.

## The SDK itself

[likeminds-chat-reactnative](https://github.com/LikeMindsCommunity/likeminds-chat-reactnative)

For the opposite approach - a chat UI hand-built directly on the data layer, bypassing the SDK - see
[likeminds-chat-reactjs-traya](https://github.com/LikeMindsCommunity/likeminds-chat-reactjs-traya).
